# バブカート

MASAO KART の派生版。メインキャラはまなちゃん。どうぶつと おかしの くにを ゆっくり走るカートゲームです。ひとりでも、家族で対戦もできます。

## できること

| 機能 | 内容 |
|---|---|
| コース3つ | 🍭 おかしのくに（キャンディ・ドーナツ・カップケーキ・お菓子の家）／🐰 どうぶつのもり（うさぎ・くま・きのこ・お花）／🌈 にじのみち |
| おしろとプリンセス | ゴール手前にお城。バルコニーでプリンセスがお出迎え |
| 小さなジャンプ台 | 1周に2〜3か所。失敗しない「ぴょーん！」 |
| 障害物は少なめ | 大きなグミが1か所だけ（ぶつかると少しゆっくり） |
| あいて（CPU） | うさぎさん・くまさん・プリンセス。強さ「ゆっくり／ふつう／はやい」 |
| やさしいアイテム | 🍭 キャンディダッシュ ⭐ きらきらスター 🍌 バナナ ☁️ マシュマロ ⚽ ボール 💤 おひるね（CPUは自分が速くなるアイテムだけ使い、まなちゃんのじゃまはしません） |
| 🍬 おかしトンネル（ボーナス） | まるいトンネルの床・壁・天井を走り、キャンディ・チョコ・グミを拾うほど最高速度アップ（200km/h→最大1,200km/h台）。大きなおかしは「ぽよーん」と飛んでいく。最後はチョコの海にダイブ。コース選択か、1位でゴールしたときの「ボーナスへ」から |
| 🍼 ばぶばぶモード | 全員がボンネット＋おしゃぶりの赤ちゃんになり、カートがベビーカー（幌・かご・大きな後輪・押し手）に変身。速さ半分、「ばぶー！」、BGMはゆっくりのきらきら星 |
| 👨‍👩‍👧 かぞくで たいせん | 家族それぞれのスマホで「かぞくで たいせん」→ 2〜4人そろったら だれかが「スタート！」。コースとばぶばぶモードは全員そろう |
| イラストの顔 | 写真を使わない人は まなちゃん／パパ／ママ／うさぎ／くま から選べる |
| おたすけハンドル | 何もしなくても道にそって走る（タイトル画面でON/OFF） |
| 走りやすさ | 道幅ひろめ・最高速度ひくめ・2周・コースから大きく外れない |
| 写真 | 「📷 なまえと しゃしん」で選んだ写真はスマホの中に保存（ファイルには入っていません）。かぞくでたいせんの時だけ相手の画面に表示するため Firebase に送られます |

## 遊び方
- iPhoneは **Safariで開く**（ホーム画面のアイコンからだと傾きセンサーが使えないことがあります）
- 横向きに持って「はしる！」。ハンドルのように傾けると曲がる・自動で進む
- 曲がらないとき・曲がりすぎるときは「📱 傾きテスト」で確認・感度を変更

## かぞくで たいせん の しくみ
- MASAO KART と同じ Firebase（monthly-party-games）の `masaokart/babukart` に保存します。ルールの変更は不要です
- Firebase のルールを閉じた（`false` にした）場合は、家族対戦はできません（ひとりで走るは使えます）
- だれでもURLを知っていれば同じロビーに入れます。気になる場合は URL に `?room=好きな名前` を付けて家族だけのルームにしてください

## 公開
GitHub のリポジトリ（例：MANA-GAME）に `mana-kart/index.html` として置くと
`https://<ユーザー名>.github.io/MANA-GAME/mana-kart/` で遊べます。
MASAO KART と同じ github.io に置いても、保存データ（写真・設定）は別々です。

## 調整（`index.html` の `CONFIG`）
| 設定名 | 内容 |
|---|---|
| `LAPS` | 周回数（2） |
| `MAX_SPEED` | 最高速度（30。ばぶばぶモードはこの半分） |
| `ROAD_WIDTH` | 道幅（24） |
| `CPU_LEVEL` | あいての強さの初期値（easy） |
| `CATCHUP` | 追い上げ補正（0.15） |
| `ASSIST` | おたすけハンドルの初期値 |
| `ROOM` | 家族対戦のルーム名（babukart） |
| `TUBE_START_CAP` / `SWEET_CAP` / `TUBE_PAD_CAP` / `TUBE_MAX_CAP` | おかしトンネルの最初の最高速度／おかし1こ・にじいろ矢印1つで上がる量／上限（×4でkm/h） |
